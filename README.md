## ✨ Características

### 🍽️ Sistema POS Gourmet
- Gestión completa de menú con 20+ platillos
- Sistema de categorías y búsqueda en tiempo real
- Carrito de compras con cálculo automático de IVA (16%)
- Integración con sistema de pagos
- Historial de órdenes
- Impresión de tickets

### 🎫 Sistema de Cupones y Lealtad
- 7 tipos de cupones diferentes
- 4 niveles de programa de lealtad (Bronce, Plata, Oro, Platino)
- Validación automática de requisitos
- Tracking de uso por usuario
- Calculadora de descuentos inteligente

### 📋 Formulario de Huéspedes
- 6 secciones completas (Información, Transporte, Habitaciones, Servicios, Actividades, Provisiones)
- Multi-idioma (Español, Inglés, Francés)
- Gestión de 11 habitaciones
- Integración con WhatsApp
- Auto-guardado en localStorage
- Validación en tiempo real

### 🎨 Galería del Chef
- Showcase de platillos signature
- Badges premium dorados
- Descripción detallada de cada creación
- Precios y conceptos culinarios

### 🌐 Características Globales
- Diseño gourmet elegante (Rojo Carmín + Blanco + Negro + Dorado)
- 100% responsive (mobile, tablet, desktop)
- Sin dependencias de servidor (static files)
- Tema consistente en todas las páginas
- Navegación tipo SPA con transiciones suaves

## 🚀 Uso

### Portal Principal
```
1. Abrir index.html
2. Navegar entre pestañas: Home, Menu, Guests, POS, About
3. Cambiar idioma con el toggle (ES/EN)
4. Alternar tema claro/oscuro
```

### Sistema POS
```
1. Buscar platillos por nombre o ingrediente
2. Filtrar por categoría
3. Agregar al carrito
4. Aplicar cupones (ej: FRANKO15)
5. Procesar pago (Cash/Card)
6. Ver historial de órdenes
```

### Sistema de Cupones
```
Cupones disponibles:
- FRANKO15: 15% descuento (nuevos usuarios, mín $500)
- BIRTHDAYCHEF: 20% + postre gratis (mes cumpleaños)
- VERANO2025: 25% en bebidas (válido hasta Sep 2025)
- REFERIDO20: 20% + $200 crédito (mín $300)
- CHEF50: $50 descuento (mín $500)
```

### Formulario de Huéspedes
```
1. Llenar información de contacto
2. Agregar detalles de transporte aeropuerto
3. Asignar habitaciones (11 disponibles)
4. Seleccionar servicios adicionales
5. Elegir actividades especiales
6. Enviar por WhatsApp o Email
```
